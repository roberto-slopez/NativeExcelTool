# NativeExcelTool v0.1.0-alpha.1

First Windows x64 alpha before the release candidate.

## Try it with data

Download and extract `NativeExcelTool-v0.1.0-alpha.1-windows-x64.zip`. Open the two workbooks under `samples/`, or run `./scripts/run-examples.ps1` with Node.js 24 and the .NET 10 SDK installed.

Both examples construct 10 realistic, fictional sales orders in their own language and produce a filterable Excel table named `SalesOrders` at `A1:H11`. Columns include customer, product, date, quantity, USD unit price/total, and paid status. Both outputs contain total sales of USD 1831.28. No Rust installation, database, credentials, or npm packages are needed to run the bundle.

## Included

- Optimized Rust CLI, Node-API addon, and C ABI DLL for C# P/Invoke.
- Runnable C# and Node.js source, native wrappers, generated schema, licenses, manifest, and checksums.
- Actual Excel outputs from both examples.
- CI validation for debug and release: Rust formatting/Clippy/tests, Node integration tests, execution of both examples, and independent XLSX data/table verification.

## Alpha scope

Windows x64 only. This is a prerelease, not an RC. Live database integration tests remain ignored pending trusted PostgreSQL/SQL Server test environments. Large-volume performance, desktop Excel/LibreOffice certification, signing, and Linux/macOS packages remain pending. No NuGet, npm, or crates.io publication is performed.
